=== GREEN — `LifecycleAdapter.kt` (object pur)

Créé `planner-plugin/src/main/kotlin/planning/lifecycle/LifecycleAdapter.kt`
(object pur, domaine `planning.lifecycle`).

API publique :

. `toContextReady(context, eagerContext, ragContext, graphifyContext, docsContext, factory)` → `AgentState.ContextReady?`
  - Concatène les 4 canaux dans `compositeContext`
  - Mappe `docsContext` → `afnorCorpus`
  - Phase default `AgentPhase.CLASSIFY` (valeur N0 défaut)
  - Factory injectable pour testabilité des fallbacks
  - `try/catch` → `null` si factory lance (fallback défensif)
. `toPlanned(plan, intention, compositeContext, afnorCorpus, classification, modelChoice, factory)` → `AgentState.Planned?`
  - Mappe `plan.epics` → `state.epics`
  - Phase default `AgentPhase.EXECUTE` (valeur N0 défaut)
  - Factory injectable pour testabilité des fallbacks
  - `try/catch` → `null` si factory lance (fallback défensif)

Pattern :
- Object pur Kotlin (zéro dépendance Gradle/coroutine, unit-testable
  plain fake) — mirror `BudgetAdapter` (domaine `planning.budget`).
- Factory injectable par paramètre défaut — pattern `BudgetAdapter.compute`
  (S-069 US-1) pour testabilité des fallbacks sans reflection.
- Fallback `null` si factory lance — pattern `BudgetAdapter.applyRelevanceBudget`
  catch `Exception` → contenu original. Ici l'absence d'état est `null`
  (l'appelant retombe sur le path actuel `PlanningContext` + `Plan` simples).
- Domaine `planning.lifecycle` nouveau (7ème domaine planner) :
  1. `planning` (core)
  2. `planning.budget`
  3. `planning.llm`
  4. `planning.lifecycle` (nouveau)
