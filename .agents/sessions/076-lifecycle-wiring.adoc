== Non-régression critique

`PlannerIntegration.kt` (codebase) appelle
`IntentionPlanner.plan(eagerContext, ragContext, graphifyContext, docsContext)`. Le contrat
d'appel (4 String + Logger → Plan) est *inchangé*. L'API lifecycle-aware est une *surcharge
additive* — le path legacy est préservé. Le flag `-Pagent.lifecycle=true` est opt-in, défaut
`false` → aucun impact sur le comportement par défaut.

== Découverte technique

Les tests fonctionnels `@integration` lifecycle utilisent `build()` (non `buildAndFail()`)
car depuis EPIC PLN-LLM-HUB (S-072), `OllamaBridge` legacy est supprimé — `LlmBuildService`
(codebase N1) résout le ChatModel via le pool 11437-11465. La propriété `-PollamaBaseUrl=http://localhost:1`
est désormais ignorée en mode `LlmBuildService` (réservée au fallback mock-LLM de
`PlanningLlmService.resolveModel`). Le LLM réel répond, le header `[LIFECYCLE]` est émis
*avant* l'appel LLM, donc l'assertion stdout est valide que le LLM réponde ou échoue.
