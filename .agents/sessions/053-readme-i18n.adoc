== Conventions appliquées

=== Marqueur de version
Chaque fichier traduit porte l'en-tête :
```
<!-- translated from README.md rev 0.0.1 -->
```
Le master EN conserve le commentaire `<!-- master source — other languages are translations of this file -->`.

=== Badges
Identiques sur les 20 fichiers (3 badges shields.io) :
- Maven Central : `education.cccp/planner-plugin`
- Gradle Plugin Portal : `education.cccp.planner`
- CI : `cheroliv/planner-gradle` workflow `test.yml`
- Licence : lien relatif `../LICENSE`

=== Markers version 0.0.1
Ligne metadata uniforme sur les 20 fichiers :
```
- **Version**: `0.0.1` · **Group**: `education.cccp` · **Plugin ID**: `education.cccp.planner`
```
(traduite dans chaque langue).

=== Switcher i18n
Le master EN pointe vers FR uniquement (`**EN** | [Français](README.fr.md)`).
Les 9 traductions portent un switcher complet à 10 liens listant toutes les langues,
avec la langue courante en gras sans lien.

=== RTL (ar, ur)
Le contenu AR et UR est écrit de droite à gauche.
Le source Markdown reste en logical order (pas de bidirectional markup),
le rendu GitHub/AsciiDoc gère le RTL nativement via la détection Unicode.
