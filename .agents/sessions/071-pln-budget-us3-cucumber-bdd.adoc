== Constat initial

L'EPIC PLN-BUDGET avait 3/4 US terminés (US-0 cadrage S-068, US-1
`BudgetAdapter` S-069, US-2 Wiring `DecomposeIntentionTask` S-070). L'US-3

parce que le `cucumberTest` global est skippé par CR-10 guard).

== Design BDD — Shared state pattern

Extension de `PlannerScenarioState` (singleton "World" pattern S-067) avec
7 champs budget : `budgetIntention`, `budgetEager`, `budgetRag`,
`budgetGraphify`, `budgetDocs`, `budgetedContext`, `budgetLogs`. Le hook
`PlannerScenarioStateReset` (`@Before`) reset tous les champs y compris
budget avant chaque scénario.

  - `The budget falls back to original content when compute returns an empty channel list`

  - `The total tokens allocated across channels respects the budget`

  - 7 Then (EAGER > RAG/GRAPHIFY/DOCS, fallback 4 channels equal,
    4 non-blank + shorter-than-or-equal, total tokens <= budget + tolerance)

. `PlannerScenarioState.kt` étendu — 7 champs budget + `reset()` étendu.

Compilation OK (pas de RED compile failure car les steps sont définis
dans la même session — baby-step BDD en un passage).

=== GREEN

  — EAGER (intention match "afnor formation qualite") > RAG/GRAPHIFY/DOCS.

`PlannerScenarioState.*`, AssertJ, English only, KDoc documentant le
pattern shared state et la déléguation à `PlannerVibecodingSteps`.
