== Pièges

1. *(S-081)* `@OutputDirectory` sur une tâche LLM `@DisableCachingByDefault` :
   les artefacts sont un **side-effect persisté**, pas une raison de sauter le
   LLM ; le stdout reste le contrat primaire.
2. *(S-081)* Jackson Kotlin : `Plan` est un data class N0, round-trip via
   `jacksonObjectMapper()` ; ne pas dupliquer un DTO de persistance.
3. *(S-081)* Les tests de wiring GradleRunner n'appellent **jamais** le LLM ;
   ils impriment la propriété `planOutputDir` d'une tâche non exécutée.
4. *(S-081)* Une CI rouge en configuration masque la dette de tests : corriger
   JDK + credentials **avant** d'interpréter un run.
