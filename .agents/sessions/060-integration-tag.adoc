== Décisions techniques

. *JUnit5 `@Tag` vs Cucumber `@integration` tag* — slider utilise le tag
  Cucumber `@integration` (filtré via `cucumber.filter.tags`). Pour les
  tests JUnit5 GradleRunner, le standard JUnit5 est `@Tag("integration")`
  (filtré via `useJUnitPlatform { excludeTags / includeTags }`). Les deux
  mécanismes coexistent : Cucumber gère ses tags via le plugin, JUnit gère
  les siens via la plateforme.
. *`excludeEngines("cucumber")` insuffisant* — `CucumberTestRunner` est
  une `@Suite` JUnit5 qui découvre l'engine cucumber. `excludeEngines`
  empêche l'exécution cucumber mais la suite reste découverte →
  `initializationError`. Ajout de
  `filter.excludeTestsMatching("planning.steps.CucumberTestRunner")` pour
  exclure la classe elle-même.
. *`tasks.withType<Test>` vs `tasks.named<Test>("test")`* — scoper
  `excludeTags` au seul `test` task évite le conflit "tag both included
  and excluded" sur `integrationTest` (qui `includeTags`).
